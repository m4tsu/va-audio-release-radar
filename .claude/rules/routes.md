# ルートファイルの規則

## dev サーバーが動いている間に `cp` や `mv` で上書きしない

TanStack Router のプラグインが `src/app/routes/**` を監視していて、上書きの瞬間に
ファイルが空になると、**新規ルートとみなして定型のひな形で書き戻す**。

**2026-09-19 に実際に起きた**。`cp` でバックアップから戻したところ `__root.tsx` が
`Hello "__root"!` の 15 行に置き換わり、SSR の `<html>` シェルとテーマスクリプトが
配信 HTML から消えた。ビルドもテストも通るので、ブラウザで見るまで気付けない。

- 編集は **Edit / Write ツール**で行う
- ファイルごと差し替えたいときは、**dev サーバーを止めてから**行う
- `src/app/routeTree.gen.ts` は生成物。手で編集しない

## `__root.tsx` の `<html>` から外してはいけないもの

`<html>` の `suppressHydrationWarning` は、head のインラインスクリプト（`themeScript`）が
最初の描画より前に `.dark` を付けるため。配色を知らないサーバーの出力と class が
食い違うのが正常で、黙るのは `<html>` 自身の属性とテキストの差分だけ（子要素の不一致は
今までどおり警告される）。**属性もスクリプトも外さないこと**。属性を外すとダークの初回
描画ごとに警告が出て、スクリプトを外すと白から黒へのちらつきが出る。
