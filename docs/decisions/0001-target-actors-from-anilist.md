# 対象声優を AniList から機械的に決める

読者: 対象声優の定義を変えようとする人
更新: 定義の出典 (AniList) や範囲 (シーズン数、言語) を変えたら superseded にして新しい決定を書く
削除: superseded になっても消さない。同じ検討を繰り返さないため

状態: accepted (2026-09-18)

## 状況

「アニメ声優の音声作品を追う」製品で、誰を対象にするかが最初の問題だった。
人が名前を挙げると、挙げた人の知識に対象が偏り、追加のたびに判断が要る。

## 決定

対象声優 = AniList にアニメ出演記録がある日本語声優。直近 12 シーズンのアニメの日本語 voiceActors を
集めて生成する。生成規則は純粋関数にしてテストで固定する。

## 帰結

- 対象は数千人規模になり、その大半は音声作品を持たない。作品 0 件の声優のページは作らない
- ストア側から声優を発見する必要が無くなり、ストアの全件取得が不要になった ([`0002`](./0002-actor-first-crawling.md))
- slug が URL に出るため、生成規則の変更は URL の変更を伴う。衝突は自動採番せず人が解決する

## 採らなかった案

- 手書きの声優リストから始める (偏りと運用負荷)
- AniList とストアの交差を対象の定義にする (ストア側からの発見が要り、コストが 1 桁以上増える)
