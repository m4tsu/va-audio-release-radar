# R18 を載せず、BL を載せる

読者: 対象作品の年齢区分や内容区分を変えようとする人
更新: R18 を扱う判断をしたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-18)

## 状況

音声作品ストアは R18 と BL を別の区分で扱う。当初は「全年齢のみ」としていたが、
それでは BL (全年齢 BL) が落ち、男性声優の対象作品を大きく失う。

## 決定

全年齢と BL を載せ、R18 を載せない。年齢区分は真偽値ではなく列挙 (`general` / `r18` / `unknown`) で持ち、
BL はストア固有の区分として解釈せずに保存する。保存してよい区分は許可集合で決め、ドメイン層に決め打ちしない。

## 帰結

- 年齢区分を公開していないストア (Audible) の作品は `unknown` で保存し、読み取り側は R18 だけを除く
- 年齢確認の背後にあるページには触れない。Cookie もセッション維持も要らない
- R18 を扱う判断をする場合は、年齢確認の導線とアフィリエイト規約・ホスティング規約の確認が別途要る

## 採らなかった案

- 全年齢のみ (BL が落ちる)
- R18 も載せる (対象声優の作品は増えず、Amazon アソシエイトの参加条件に抵触して送客経路を失うリスクだけが残る。
  測定は `docs/research/adult-scope-2026-09-18.md`)
- 4 値の年齢区分 (`general` / `bl` / `r18` / `r18_bl`)。BL は年齢区分ではない
