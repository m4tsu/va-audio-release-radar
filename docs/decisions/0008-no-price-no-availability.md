# 作品に価格と在庫状態を持たない

読者: 作品ページに価格や在庫を出そうとする人。既知の作品を取り直す周期を足そうとする人
更新: 価格か在庫状態を持つ判断をしたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-20)

## 状況

価格追跡はしないと決めている ([`product.md`](../product.md) の「作らないもの」) のに価格を保存して作品ページに出しており、
取り直さない限り古くなる。在庫状態も保存して画面が読んでいるが、取り込みが常に同じ値を書くので変わらない。
価格を正しく保つには全ストアの既知作品を取り直し続ける必要があり、往復が作品数に比例して増える。

## 決定

価格・定価・在庫状態 (買えるかどうかの推定) を持たない。作品ページはストアへのリンク先を正とし、価格を出さない。
ストアが販売終了を明示したときに限り、その listing を取り下げる。取り下げは削除ではなく、推定でも行わない。

## 帰結

- 価格のために既知の作品を取り直す周期は要らない。取り直すのは販売中の印を持つ DLsite の詳細だけで
  ([`dlsite.md`](../stores/dlsite.md) の「product.json」。販売終了時の値は未確認)、月次の巡回に含める
  ([`0007`](./0007-daily-crawl-from-store-feeds.md))。所要は作品数に比例し、GitHub Actions に収まるかは未測定
- Audible とポケットドラマ CD は販売終了を明示する手段が無いので、ストアで確認する導線を出すだけにする
- 取り下げた行は残る ([`0009`](./0009-actor-list-append-only.md) の「削除の経路を持たない」を破らない)

## 採らなかった案

- 全ストアの既知作品を取り直して価格を更新する。価格追跡をしない製品に対して往復だけが増える
- 取得時点の価格を日付つきで出す。古い価格は誤解を生み、ストアで見れば済む
- 一覧に出なくなった作品を販売終了と推定する。検索には取りこぼしがあり、推定が外れると買える作品を隠す
