# 作品に価格と在庫状態を持たない

読者: 作品ページに価格や在庫を出そうとする人。既知の作品を取り直す周期を足そうとする人
更新: 価格か在庫状態を持つ判断をしたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-20)

## 状況

価格追跡はしないと決めている ([`product.md`](../product.md) の「作らないもの」) のに価格を保存して
作品ページに出しており、既知の作品を取り直さない限り古くなる。在庫状態は保存しているが、更新する経路も
読む画面も無い。どちらも「既知の作品の詳細を取り直す」理由になり、相手サイトへの往復を増やす。

## 決定

価格・定価・在庫状態を持たない。作品ページはストアへのリンク先を正とし、価格を出さない。

## 帰結

- 既知の作品は発売日と出演者が発売後に変わらないので、詳細を取り直す周期の運用が要らない
- 販売終了によるリンク切れは残る。DLsite は詳細に販売中の印があるので月次の巡回で外す
  ([`0007`](./0007-daily-crawl-from-store-feeds.md))。Audible とポケットドラマ CD は検出のコストが
  見合わないので、ストアで確認する導線を出すだけにする

## 採らなかった案

- 月次で全作品の詳細を取り直して価格を更新する。価格追跡をしない製品に対して往復だけが増える
- 取得時点の価格を日付つきで出す。古い価格は誤解を生み、ストアで見れば済む
