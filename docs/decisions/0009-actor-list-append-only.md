# 対象声優リストは追加だけを行う

読者: 対象声優をリストから消したり、名前を変えたりしようとする人
更新: 削除や改名を扱う判断をしたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-20)

## 状況

対象声優は AniList の直近 12 シーズンから生成する ([`0001`](./0001-target-actors-from-anilist.md))。
シーズンが進むと窓から外れる声優、AniList 側で名前が変わる声優が出る。声優ページの URL は slug で決まり、
変えると URL が変わる。直近 12 シーズンという窓は取得対象を絞るための条件であり、一度対象になった声優を
外す理由にはならない。

## 決定

生成のたびに増えた声優だけを足す。窓から外れた声優も消さず、ページも残す。
AniList 側の改名は別名義として足し、正式名と slug は変えない。

## 帰結

- 声優と作品に削除の経路を持たない。データは単調に増える。販売終了の取り下げは行を残す
  ([`0008`](./0008-no-price-no-availability.md))
- シーズン更新の作業は「増えた声優を声優起点で引く」だけになる ([`0007`](./0007-daily-crawl-from-store-feeds.md))
- リストの生成には前回との差分を出す仕組みが要る

## 採らなかった案

- 窓から外れた声優を消す。URL が消え、その声優の作品も孤立する
- 改名を正式名の変更として扱う。slug が変わり、URL が変わる
