# back catalog は取得できた範囲と定義する

読者: 網羅率を上げようとする人。声優ページに全作品が無い理由を説明する人
更新: 網羅を約束する判断をしたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-20)

## 状況

各ストアの検索は robots.txt の制約で取れる件数に上限がある (DLsite は並び順 2 通りの 1 ページ目、
Audible はページ数の上限。値はコードが持つ)。上限を超える作品数の声優では back catalog が欠ける。
上限は相手の規約なので越えられない。

## 決定

back catalog は「規約の範囲で取得できた作品」と定義し、網羅を約束しない。
上限に当たった声優のページには、ストアでその声優の全作品を見るリンクを出す。
取りこぼしは監視するが、埋める義務は持たない。

## 帰結

- 網羅率の記録 (総件数と、取り切れたかの真偽) は埋めるためではなく利用者に示すために残す
- 上限に当たった声優は月次の補完巡回で洗い出す ([`0007`](./0007-daily-crawl-from-store-feeds.md))

## 採らなかった案

- 2 ページ目以降を取る。DLsite は robots.txt の意図に反し、Audible はページ数の上限を置いた根拠
  ([`audible.md`](../stores/audible.md)) を崩す
- 並び順を増やして和集合を取る。Audible は robots.txt が禁じている
