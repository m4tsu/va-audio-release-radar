# DLsite は `/home/` と `/garumani/` の 2 フロアを引く

読者: DLsite で引くフロアを増やそう / 減らそうとする人
更新: 引くフロアを変えたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-21)

## 状況

`/home/` は「全年齢の同人」であって「全年齢のすべて」ではない。商業 (`BJ`) の女性向け全年齢音声は
`/home/` の声優検索に出ない。男性声優ではここが大きく効き、1 フロアだけでは対象作品の大半を落とす
(件数は [`dlsite-female-floors-2026-09-20.md`](../research/dlsite-female-floors-2026-09-20.md))。
R18 を含むフロア (`/girls/` `/bl/` `/maniax/`) は [`0003-no-r18-keep-bl.md`](./0003-no-r18-keep-bl.md) で
対象外にしてある。

## 決定

声優 1 名につき `/home/` と `/garumani/` の両方を引き、作品 ID で束ねて 1 回の走行の結果にまとめる。
どちらのフロアも全体が全年齢なので、検索 URL に年齢の指定は付けない。

## 帰結

- 声優 1 名あたりの往復がフロアの数に比例する。取得コストの見積もりは
  [`docs/stores/dlsite.md`](../stores/dlsite.md) の「レート間隔」で計算し直す
- 総件数はフロアごとに返るので和を取る。同じ作品が両方に出ると取得件数と和が一致しないため、
  取り切れたかどうかの判定は和ではなくフロアごとに持つ
- 片方のフロアが落ちても、取れた側の結果で走行を続け、落ちた走行は「取り切れていない」として記録する
- フロアは引く入口でしかない。作品がどの区分に属するかは `product.json` の `site_id` だけが決める

## 採らなかった案

- `/home/` だけを引く (男性声優の対象作品をほぼ落とす)
- `/girls/` `/bl/` に `age_category[0]/general` を足して引く
  (結果が `/home/` と重なり、測定した範囲で新しい作品が出なかった。R18 フロアに触れる理由が無い)
- sitemap で全件を引いてから絞る (声優起点より桁違いに時間がかかる。所要は
  [`docs/stores/dlsite.md`](../stores/dlsite.md) の「レート間隔」。
  [`0002-actor-first-crawling.md`](./0002-actor-first-crawling.md) で退けた案と同じ)
