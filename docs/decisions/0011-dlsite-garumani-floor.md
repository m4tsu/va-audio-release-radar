# DLsite は全年齢サイトに加えて女性向け全年齢フロアも取る

読者: DLsite のどのフロアを取得するか変えようとする人
更新: 取得するフロアを変えたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-20)

## 状況

DLsite の全年齢サイト `/home/` だけを取っていた。`/home/` は「全年齢の同人」であって
「全年齢のすべて」ではなく、商業の女性向け全年齢音声 (BL ドラマ CD など) は
女性向け全年齢フロア `/garumani/` にしか出ない。代表 10 名で比べると 116 件が 182 件になり、
斉藤壮馬は 1 件が 52 件になる ([`dlsite-female-floors-2026-09-20.md`](../research/dlsite-female-floors-2026-09-20.md))。
男性声優をフォローしたときに出る作品がほぼ空だった。

## 決定

DLsite は `/home/` と `/garumani/` の 2 フロアを取る。R18 を含むフロア
(`/maniax/` `/girls/` `/bl/`) は取らない ([`0003`](./0003-no-r18-keep-bl.md) のまま)。
実装は別に切る。

## 帰結

- 作品 ID はフロアをまたいで同一なので、2 フロアから同じ ID を拾ったら 1 行にまとまる必要がある
- `storeSection` に `bldrama` / `girlsdrama` という値が新しく入る。解釈せずに保存する方針は変えない
- `/garumani/` の新着一覧には発売日が未来の予約作品が出る。`/home/` には出ない。
  画面での扱いを決める必要がある
- 日次の増分は 1 日 2 リクエスト・約 20 秒。初期構築は `/home/` と同じく分割が要る

## 採らなかった案

- `/home/` のままにする。男性声優の作品が 1/53 しか見えない
- `/girls/` と `/bl/` に `age_category[0]/general` を付けて足す。結果が `/home/` と重なり、
  測定した範囲では新しい作品が 1 件も出なかった
- R18 フロアも取る。[`0003`](./0003-no-r18-keep-bl.md) を覆すことになり、この調査に増やす根拠は無い
