# 音声作品が無い声優もフォローできるようにする

読者: 声優ページが 200 で返る条件と、キャスト一覧に誰が並ぶかを変えようとする人
更新: 音声作品の無い声優をフォロー対象から外す判断をしたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-21)

## 状況

対象声優は AniList のアニメ出演から機械的に決める ([`0001`](./0001-target-actors-from-anilist.md))。
その大半は音声作品をまだ出していない。これまでは音声作品が 1 件も無い声優のページを 404 にし、
一覧・検索・アニメのキャスト一覧からも外していたので、その声優をフォローする手段が無かった。
「初めての 1 本」を知らせることは、このサービスが約束している「取りこぼさず知らせる」の一部にあたる。

## 決定

音声作品が 1 件も無い声優も、出演アニメがあればページを出し、一覧・検索・アニメのキャスト一覧にも載せる。
そのページは noindex とし sitemap にも載せない。中身が名前と出演アニメだけで、検索から読ませる価値が無いため。
音声作品も出演アニメも無い声優は従来どおり 404。

## 帰結

- 声優一覧と検索に、出演アニメがある声優が全員載る。既定の並び (作品数の多い順) では
  音声作品のある声優の後ろに来る
- アニメ 1 作品のページは出演者を絞らずに並べる。ページを出すかどうかの条件は変えないので、
  音声作品を持つ出演者が 0 人のアニメは 404 のまま
- 検索結果の上限に、音声作品の無い声優も数えられる
- 声優一覧は全員を SSR で出すので、返す HTML が声優数に比例して大きくなる

## 採らなかった案

- 音声作品が無い声優もインデックスさせる。名前しか無いページが対象声優の数だけ並び、
  サイト全体の評価を下げる
- フォローだけを受け付けてページは 404 のままにする。フォローの前に「この人で合っているか」を
  出演アニメで確かめる場所が無くなる
