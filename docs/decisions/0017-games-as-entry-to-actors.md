# ゲームは出演者から声優に入る入口としてだけ持つ

読者: ゲームの情報を画面やデータに足そうとする人。「声優事典 / キャスト DB は作らない」との線引きを確かめたい人
更新: ゲームの持ち方を変えたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-25)

## 状況

声優に入る入口はアニメの出演だけで、ゲームで声優を知った人には入口が無い。
一方で `docs/product.md` の「作らないもの」に声優事典とキャスト DB があり、判断規則は「フォロー情報があるから成立するか」。
この製品の価値は声優の音声作品を探すことにあるので、声優ページに出演ゲームを並べても音声作品には近づかない。
音声作品に近づくのは、ゲームのキャラクターから、その声の人のページへ入る向きだけである。

## 決定

- **ゲーム 1 本に 1 ページを置き、キャラクターと声優の対を並べる。** 各行から声優ページへ入り、フォローできる
- **載せるのは台帳の対象声優の行だけ。** 対象声優の定義 (AniList にアニメ出演記録がある日本語声優) は変えない。
  ゲームにしか出ていない声優は増やさない
- **持つのはタイトル名・キャラクター名・声優・出どころの URL と取得日だけ。** あらすじ・ジャンル・配信状態・
  イベント・キャラの性能・画像・ボイスは持たない
- **タイトルは人が選んだ一覧に載せたものだけ。** 選び方と供給元は [`0018`](./0018-game-cast-from-official-sites.md)。
  R18 のタイトルは一覧に入れる時点で外す
- 通知は音声作品のダイジェストのまま。ゲームの新着は通知しない

## 帰結

- キャスト一覧を並べる画面ができる。キャスト DB に寄らない歯止めは、台帳の声優の行だけを出すこと、
  一覧に載せたタイトルだけを出すこと、持つ項目を上の 5 つに限ること
- 台帳に居ない声優の行は画面に出ないので、ゲームページは全キャストの一覧にはならない。そのことを画面に書く
- ゲームは入れ替わりが少なく、ページは月に 1 回の引き直しで足りる

## 採らなかった案

- **声優ページに出演ゲームを並べるだけにする。** 声優 → ゲームの向きは音声作品を探す役に立たない
- **出演している対象声優の多い順に、タイトルを機械的に選ぶ。** アニメと違ってゲームは入れ替わらず、
  長く人気のあるタイトルは少ない。多くを載せる利点が薄い
- **ゲームを網羅する。** キャスト DB そのものになる
