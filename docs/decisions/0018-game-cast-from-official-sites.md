# ゲームのキャストはタイトルごとに公式サイトから取る

読者: ゲームのタイトルを足す人。キャストの供給元を変えようとする人
更新: 供給元の選び方か、規約の読みを変えたら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-25)。[`0017`](./0017-games-as-entry-to-actors.md) のタイトルの選び方と供給元を決める

## 状況

ゲームのキャストを持つ DB・API は、商用で使えないか、声優の項目が無い
([`game-cast-wikipedia-2026-09-23.md`](../research/game-cast-wikipedia-2026-09-23.md))。
ja / zh の Wikipedia からは多くのタイトルが取れるが、ゼンレスゾーンゼロと鳴潮は載っていない。
1 本でも個別に取るタイトルがあれば、個別に取る流れはどのみち要る。Wikipedia は信頼性も新しさも保証が弱い。
公式サイトが全キャラの声優を文字か JSON で載せているのは、調べた 39 本中 20 本。ただし、規約の条項がほぼ全部に
ある ([`game-cast-official-sites-2026-09-25.md`](../research/game-cast-official-sites-2026-09-25.md))。

## 決定

- **供給元はタイトルごとに 1 つ。原則はそのゲームの公式サイト。** 公式サイトが実装キャラ全体の声優を文字か JSON で
  載せていないタイトルは載せない。一部のキャラだけを載せるサイト (グランブルーファンタジー、Fate/Grand Order、
  ブルーアーカイブ、雀魂、白猫プロジェクト、ファイアーエムブレム ヒーローズ など) も載せない
- **規約はこう読む。** キャラ名と声優名の対は事実であり、複製・転載の条項の対象 (著作物) に当たらない。
  ゲームの規約の営利目的の禁止は、ゲームの利用者に向けたものと読む。画像・説明文・ボイスは取らず、載せない。
  **自動取得・スクレイピング・クローラ・データマイニングを名指しで禁じるサイトは使わない** (Shadowverse、
  勝利の女神:NIKKE、Identity V 第五人格)
- **鳴潮だけは攻略サイトの GameWith から取る。** 公式サイトに声優が文字で無い。攻略サイトの規約にも同じ読みを当てる。
  GameWith の robots.txt には禁止が無い。Game8 の robots.txt は収集系のボット約 40 種を名指しで禁じており、
  収集を断る意図と読む。アルテマは声優が分からない行を含む。抜き出せた対は GameWith が最も多い
- **抽出はタイトルごとの決定的なコードで行い、LLM は使わない。** 同じページの作りを共有する組 (HoYoverse の 3 本、
  アイドル名鑑の 3 ブランド) は 1 本にまとめる。声優の照合は `src/domain/identity.ts` の規則に従い、
  複数に当たったものは捨てる
- 最初に載せるのは次の 20 本。一覧の正は、実装後はクローラーのタイトル一覧 (コード) が持つ

## 帰結

- 抽出のコードはタイトルの数に近い本数になる。ページの作りが変わると取れなくなるので、取れた行が 0 のときは
  前回の行を消さずに失敗として扱う
- タイトルを足すときは、公式サイトの robots.txt と規約を読み、`docs/stores/` に引用してから一覧に足す
- アークナイツ・プリンセスコネクト!Re:Dive などは、Wikipedia には載っているが公式サイトに無いので入らない
- 規約の読みが運営元と違ったと分かったら、そのタイトルを取り下げる
- Wikipedia を使わないので、ゲームページに CC BY-SA の表示は要らない。出どころは公式サイトへのリンクで示す

## 採らなかった案

- **ja / zh の Wikipedia を主な供給元にする。** 個別に取るタイトルはどのみち出る。信頼性と新しさの保証も弱い
- **攻略サイトを主な供給元にする。** 規約が商業目的の利用を名指しで禁じており、一次情報でもない。
  公式サイトに声優が無い鳴潮にだけ使う
- **規約の条項があるサイトは、運営元への照会が済むまで使わない。** 照会なしで使えるのが数本になる
- **一部のキャラだけを載せる公式サイトのタイトルも載せる。** ゲームページが出演者のごく一部しか示さず、
  そのゲームのキャスト一覧だと読まれる
