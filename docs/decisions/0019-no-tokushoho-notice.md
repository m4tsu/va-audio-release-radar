# 特定商取引法に基づく表示を置かず、運営者は利用規約とプライバシーポリシーで名乗る

読者: 運営者の表記や連絡先を変えようとする人。特定商取引法に基づく表示や「広告」「PR」の表記を足そうとする人。アフィリエイトプログラムを足す人
更新: 商品や役務を自ら販売する機能を足すか、表示文の義務があるアフィリエイトプログラムに参加したら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-26)

## 状況

利用規約とプライバシーポリシーは運営者を「運営者」としか書いておらず、利用者からも販売サイトからも
誰が運営していてどこへ連絡すればよいかが特定できなかった。
名乗り方を決めるにあたり、運営者情報の掲載を法令とアフィリエイトの規約が求めるかを確かめた (2026-09-23)。

- 特定商取引法の通信販売の規定は「販売業者又は役務提供事業者」に掛かる
  (<https://www.no-trouble.caa.go.jp/what/mailorder/>)。本サービスは商品を販売せず、販売サイトへ案内するだけなので販売業者に当たらない
- 景品表示法のステマ規制は、表示の対象となる商品を自ら供給する者に掛かる。本サービスはアフィリエイトの対象となる作品を供給しないので、
  「広告」「PR」の表記は法的義務ではない
- Amazon アソシエイトは、運営規約 第5条で所定の表示文をサイトに目立つ形で出すことを求める
  (<https://affiliate.amazon.co.jp/help/operating/agreement>)
- DLsite のアフィリエイトパートナー規約には、運営者情報の掲載義務も所定の表示文も見当たらない
  (<https://www.dlsite.com/home/affiliate/regulations>)

## 決定

特定商取引法に基づく表示の画面は作らない。運営者は、個人がサービス名を冠した名称で名乗り、
利用規約とプライバシーポリシーの本文に出す。表記は `src/app/legal/index.ts` の `OPERATOR_NAME` が持つ。
連絡先はサイト内のお問い合わせ画面とし、外部の窓口 (`CONTACT_URL`) は設定しない。

Amazon アソシエイトには参加しないので、運営規約 第5条の表示文は出さない。

## 帰結

- 住所と電話番号は画面に出さない。出す義務が無いため
- 利用規約の管轄裁判所は「運営者の住所地」で定めており、住所を出さなくても条文は成り立つ
- 外部の窓口を足すときは `CONTACT_URL` を設定するだけで、両文書のお問い合わせの条に並んで出る
- Amazon アソシエイトに参加する判断をしたら、運営規約 第5条の表示文を日本語と英語で画面に出す必要が生じる

## 採らなかった案

- 特定商取引法に基づく表示を任意で置く (販売業者に当たらないのに置くと、売り手であるかのように読める。
  載せる項目の多くは住所と電話番号で、出す義務の無いものを出すことになる)
- 本名で名乗る (法令上もアフィリエイトの規約上も求められていない)
- 「広告」「PR」の表記を各リンクに付ける (法的義務ではなく、外部リンクとアフィリエイトへの参加は利用規約で説明している)
