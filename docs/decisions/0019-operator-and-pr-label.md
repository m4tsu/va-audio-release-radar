# 特定商取引法に基づく表示を置かず、運営者は規約で名乗り、アフィリエイトリンクに PR と表記する

読者: 運営者の表記や連絡先を変えようとする人。特定商取引法に基づく表示や広告表記を足す・外す人。アフィリエイトプログラムを足す人
更新: 商品や役務を自ら販売する機能を足すか、表示の義務が違うアフィリエイトプログラムに参加・脱退したら superseded にして新しい決定を書く
削除: superseded になっても消さない

状態: accepted (2026-09-26)

## 状況

利用規約とプライバシーポリシーは運営者を「運営者」としか書いておらず、利用者からも販売サイトからも
誰が運営していてどこへ連絡すればよいかが特定できなかった。
名乗り方を決めるにあたり、運営者情報と広告の表示を法令とアフィリエイトの規約が求めるかを確かめた。

- 特定商取引法の通信販売の規定は「販売業者又は役務提供事業者」に掛かる
  (<https://www.no-trouble.caa.go.jp/what/mailorder/>、2026-09-23 確認)。本サービスは商品を販売せず、販売サイトへ案内するだけなので販売業者に当たらない
- 景品表示法のステマ規制で表示の義務を負うのは、商品を供給する広告主である。本サービスはアフィリエイトの対象となる作品を供給しないので、
  法令上の表示義務者ではない
- バリューコマースのアフィリエイトサイト運営者利用規約は、第1条で付随するガイドラインの遵守を、第11条第4項で
  「広告を掲載するにあたり、原則、広告であることの表示を行う」ことを求める
  (<https://www.valuecommerce.ne.jp/st_affiliate/terms.html>、2025-07-16 改定版を 2026-09-26 確認)。
  ガイドラインは、アフィリエイトリンクを載せるページで、該当する広告を閲覧するまでに見える位置に「PR」などの表記を置くよう求める
  (<https://www.valuecommerce.ne.jp/policy/as/ad.html>、2026-09-26 確認)。運営者情報の掲載はどちらも求めない
- Amazon アソシエイトは、運営規約 第5条で所定の表示文をサイトに目立つ形で出すことを求める
  (<https://affiliate.amazon.co.jp/help/operating/agreement>、2026-09-23 確認)
- DLsite のアフィリエイトパートナー規約には、運営者情報の掲載義務も所定の表示文も見当たらない
  (<https://www.dlsite.com/home/affiliate/regulations>、2026-09-23 確認)

## 決定

特定商取引法に基づく表示の画面は作らない。運営者は、個人がサービス名を冠した名称で名乗り、
利用規約とプライバシーポリシーの本文に出す。表記は `src/app/legal/index.ts` の `OPERATOR_NAME` が持つ。
連絡先はサイト内のお問い合わせ画面とし、外部の窓口 (`CONTACT_URL`) は設定しない。

アフィリエイトリンクには、リンクより前に「PR」と表記する (`src/app/components/pr-label.tsx`)。
義務の出どころはバリューコマースの利用規約とガイドラインだが、DLsite のアフィリエイトリンクにも付ける。
作品ページでは各ストアのリンクが同じ区画に並び、一部にだけ付けると、付いていないリンクが報酬の付かないリンクだと読めてしまうため。
正規 URL に落ちたリンクは報酬が付かないので付けない。

Amazon アソシエイトには参加しないので、運営規約 第5条の表示文は出さない。

## 帰結

- 住所と電話番号は画面に出さない。出す義務が無いため
- 利用規約の管轄裁判所は「運営者の住所地」で定めており、住所を出さなくても条文は成り立つ
- 外部の窓口を足すときは `CONTACT_URL` を設定するだけで、両文書のお問い合わせの条に並んで出る
- アフィリエイトリンクを出す部品を足すときは、同じ表記を前に置く
- Amazon アソシエイトに参加する判断をしたら、運営規約 第5条の表示文を日本語と英語で画面に出す必要が生じる

## 採らなかった案

- 特定商取引法に基づく表示を任意で置く (販売業者に当たらないのに置くと、売り手であるかのように読める。
  載せる項目の多くは住所と電話番号で、出す義務の無いものを出すことになる)
- 本名で名乗る (法令上もアフィリエイトの規約上も求められていない)
- 表記を「広告」にする (ガイドラインはどちらも例に挙げている。「PR」は日本語と英語で同じ語で通じる)
- 表記をページの上部に 1 度だけ置く (ガイドラインの「該当する広告を閲覧するまでに見える位置」を、リンクのそばの方が確実に満たす)
- バリューコマース経由のリンクにだけ付ける (同じ区画で表記の有無が分かれる)
