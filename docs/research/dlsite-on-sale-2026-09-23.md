# DLsite の `on_sale` は販売中かどうかを表す (2026-09-23)

読者: 販売終了の作品を取り下げる判定を変える人
更新: しない (測定値は日付とセットで固定する)
削除: しない

## 何を測ったか

`docs/stores/dlsite.md` は `product.json` の `on_sale` を「販売中の作品では 1。販売終了の作品で
どの値になるかは未確認」と書いていた。取り下げ ([`decisions/0008`](../decisions/0008-no-price-no-availability.md))
を実装するには、販売終了の作品が何を返すかが要る。

手元に残っていた 2026-09-17 と 09-18 の `product.json` の応答 2,275 件を数え、
そのうち値が分かれた作品を 2026-09-23 に引き直した。

## 値の分布 (2026-09-17 / 09-18 に取得した 2,275 件)

| `on_sale` | 件数 | 取得元 |
|---:|---:|---|
| 1 | 2,138 | 新着一覧と声優検索に出た作品 |
| 0 | 137 | sitemap から引いた作品のうち、一覧には出なかったもの |

- **一覧 (新着・検索) に出た作品は 1 件残らず `on_sale: 1`** だった
- **`on_sale: 0` の 137 件はすべて sitemap 起点**で、こちらが保存した作品には 1 件も含まれない
- 137 件はすべて `is_reserve_work: false` で、`regist_date` も過去。未発売ではない
- 137 件はすべて翻訳版 (【韓国語版】【繁体中文版】など) だった

## 5 日後に引き直した結果 (2026-09-23)

| workno | 09-18 | 09-23 |
|---|---:|---:|
| RJ01647308 | 0 | 0 |
| RJ01648112 | 0 | 0 |
| RJ087746 (対照) | 1 | 1 |
| RJ087745 (対照) | 1 | 1 |
| RJ199017 (対照) | 1 | 1 |
| VJ011120 (対照) | 1 | 1 |
| RJ199041 (対照) | 1 | 1 |
| RJ199052 (対照) | 1 | 1 |

対照は手元の DB で一番古い発売日 6 件 (2011〜2017)。**古くても売られていれば 1 のまま**で、
0 は 5 日経っても 0 だった。一時的な値ではない。

## 何が言えるか

- **`on_sale` は「今買えるか」を表す。** 0 は買えない状態で、少なくとも 5 日は続く
- 一覧に出る作品は必ず 1 なので、**一覧を起点に保存した作品が 0 に変わったら、買えなくなったということ**
- `is_reserve_work: true` の作品は 2,275 件の中に 1 件も無かった。**未発売の作品が
  `on_sale: 0` を返すかどうかは測れていない。** 取り下げの判定は `is_reserve_work` が
  立っていないことも条件にする (未発売の作品を取り下げないため)

## 測れていないこと

- **同じ作品が 1 から 0 に変わる瞬間**を観測していない。上の結論は「一覧に出る作品は必ず 1、
  sitemap にしか無い作品に 0 が出る」という分布から言っている
- 0 の作品がその後 1 に戻ることがあるか (再販)
- 0 以外の値 (2 以上) があるか。2,275 件では 0 と 1 しか出ていない
