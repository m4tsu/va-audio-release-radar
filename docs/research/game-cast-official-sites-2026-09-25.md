## 0. 調査方法

- 取得は `work/` に置いた使い捨てのスクリプトから `crawler/lib/fetch.ts` の `fetchText` を呼んで行った
  (ホストごとに既定の間隔、ブラウザ相当の UA、リダイレクトは 3 回まで手で追う)。git には残していない
- HTML に本文が無い SPA は、ヘッドレスの Chromium でページを 1〜2 回開き、ページ自身が呼ぶ XHR を記録した
- 最初に robots.txt を取り、禁止パスには触れていない。1 タイトルの取得は 30 リクエストまでとし、
  個別ページが多いタイトルは標本だけ取った (表の「標本」)
- 「台帳」は 2026-09-25 のローカル D1 の対象声優 2,569 人。声優名を NFKC にかけ空白と中黒を除いて完全一致で数えた。
  対を抜き出せたタイトルは抜いた声優名だけで、抜けなかったタイトルはページ本文全体で数えた (後者は偶然の一致を含む)
- 規約は、公式サイトのフッターから辿れる利用規約・サイトポリシー・コンテンツ利用ガイドラインを読み、
  自動取得、複製・転載、営利目的の利用に触れる条項を拾った

## 1. ゼンレスゾーンゼロと鳴潮

**ゼンレスゾーンゼロの公式サイトは、キャラクターと日本語の声優を JSON で返している。** キャラクターのページは
SPA で、ページが呼ぶ HoYoverse のコンテンツ API (`sg-public-api-static.hoyoverse.com` の `getContentList`) の
各項目の拡張欄に、キャラ名・声優名・声優の言語 (「日」) が入る。キャラクターは陣営ごとのチャンネルに分かれて
おり、チャンネル番号はページの JS に書かれていないので番号を順に引いて探した (250〜420 番を 1 本ずつ引いた)。

| 測ったもの | 値 |
|---|---|
| キャラクターの項目を持つチャンネル | 6 本 |
| キャラと日本語の声優の対 | 61 行 |
| うち台帳に一致した行 / 異なり人数 | 57 行 / 55 人 |
| 一致しなかった声優名 | `斋藤千和` (簡体字の「斋」)、`安野希世乃/玄田哲章` (1 欄に 2 人)、`M・A・O`、`Machico` |

**鳴潮の公式サイトは声優を文字で載せていない。** ページの本文とページが引く JSON (`MainMenu.json`、記事ごとの
`article/<id>.json`) を見た。共鳴者は名前 (漢字・かな・英字) の一覧だけで、「共鳴者紹介」の記事 40 本は
画像で、取った 2 本の本文に「CV」「声優」「ボイス」の文字が無かった。公式サイトの robots.txt は `User-agent: *` の
1 行だけで禁止は無い。JSON を置く CDN (`hw-media-cdn-mingchao.kurogame.com`) の robots.txt は 404。

**攻略サイトには両タイトルとも声優の一覧がある。** 声優一覧のページを 1 枚ずつ取り、本文に現れる台帳の声優を
数えた (代表作の欄などに出る別人を含みうる)。

| サイト | ゼンレスゾーンゼロ | 鳴潮 |
|---|---:|---:|
| Game8 | 63 | 59 |
| GameWith | 61 | 60 |
| アルテマ | 未取得 | 23 (「現在声優が判明していません」の行を含む) |

鳴潮の 2 サイトは、表の行から「キャラ名と声優名」の対を抜き出し、抜いた声優名だけで数え直した。

| サイト | 対の行数 | 異なり声優 | うち台帳 | 抽出の形 |
|---|---:|---:|---:|---|
| GameWith | 62 | 55 | 52 | 1 行 = キャラ名のリンク、声優名 (複数は「、」区切り) とそのかな、代表作 |
| Game8 | 52 | 52 | 48 | キャラごとの見出しと表。声優名は代表作の前の区切り線の手前 |

GameWith で台帳に一致しなかった声優名は `Lynn`、`白熊寬嗣` (「寛」でなく「寬」)、`伊吹誓乃`。

2026-09-25 の robots.txt は、Game8 が `User-agent: *` のグループを持たず収集系のボット約 40 種を名指しで
`Disallow: /` にしている。GameWith は `Sitemap:` の 1 行だけ。規約はどちらも商業目的の利用を禁じる条項を持つ
(GameWith の引用は [`docs/stores/gamewith.md`](../stores/gamewith.md))。Game8 は商業利用の問い合わせ窓口を規約に置いている。

## 2. HoYoverse の他のタイトル

ゼンレスゾーンゼロと同じコンテンツ API を、各公式サイトのキャラクターページが呼んでいる。

| タイトル | 載り方 | キャラの項目 | 台帳の異なり人数 |
|---|---|---:|---:|
| 原神 | 拡張欄に日本語の声優名 (欄の名前は数字の ID) | 120 | 109 |
| 崩壊:スターレイル | 拡張欄 `cv1` に日本語の声優名 | 87 (1 リクエスト) | 67 |
| 崩壊3rd | 拡張欄に声優の欄が無い | 84 | 0 |

`genshin.hoyoverse.com` / `hsr.hoyoverse.com` / `houkai3rd.hoyoverse.com` / `zenless.hoyoverse.com` と
API のホストの robots.txt はいずれも 404。原神・崩壊:スターレイル・ゼンレスゾーンゼロの利用規約は、どれも
「本サービス」をゲームとそれに関連して提供する一切のサービスと定め、禁止事項に次の 2 行を置く。

> 当社の承認を得ずに行われる、営利を目的とする行為。

> 外部ツール(BOT)もしくはCOGNOSPHERE PTE. LTD. から公式に提供していないプログラムを使用し、自分が有利にゲーム進行し、もしくは正常なサービス利用を妨げる行為。

条項の全体は [`docs/stores/hoyoverse.md`](../stores/hoyoverse.md)。

## 4. 読み取れること

- 公式サイトが全キャラの声優を文字か JSON で載せているのは、原神・崩壊:スターレイル・ゼンレスゾーンゼロ・
  ウマ娘・ドールズフロントライン2・ヘブンバーンズレッド・A3!・あんさんぶるスターズ!!・バンドリ!・D4DJ・
  アイドルマスターの各ブランド・学園アイドルマスター・プロジェクトセカイ・魔法使いの約束・刀剣乱舞ONLINE など。
  グランブルーファンタジー・FGO・ブルーアーカイブ・雀魂・NIKKE・白猫・FE ヒーローズは一部のキャラだけ
- 公式サイトに声優が無いタイトル (アークナイツ・プリコネ・アズールレーン・崩壊3rd・鳴潮・艦これ・第五人格・
  黒猫のウィズ・モンスト) のうち、アークナイツとプリコネは ja.wikipedia の記事に 100 人以上が載っている
  ([`game-cast-wikipedia-2026-09-23.md`](./game-cast-wikipedia-2026-09-23.md))
- 規約の条項が全く見つからなかったのは、ドールズフロントライン2・アサルトリリィ Last Bullet・刀剣乱舞ONLINE の 3 本だけ。
  残りは転載か営利か自動取得のどれかに触れる条項を持つ
- ページの形はタイトルごとに違い、同じ運営でも共有されない (HoYoverse の 3 本とアイドルマスターの 3 ブランドは例外)。
  個別の抽出器は、共有できる組を除いて 1 タイトル 1 本になる
