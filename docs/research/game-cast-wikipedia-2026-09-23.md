## 1. ゲームの DB・API

| 供給元 | 可否 | 根拠 |
|---|:--:|---|
| AniList | × | API のスキーマで `MediaType` は `ANIME` と `MANGA` だけ。ゲームという語が出るのは `MediaSource` (アニメの原作の種類) だけ |
| IGDB | × | v4 のエンドポイントに `person` も `credit` も無い。`Character` のフィールドに声優が無い。無料枠は非商用、商用はパートナープログラムと IGDB.com への表示が条件 |
| VNDB | × | 非商用が前提。対象はビジュアルノベル |
| MobyGames | × | 商用 API は月 $4,999.99。商用利用は書面の許可が要る |
| メディア芸術データベース | × | ゲームは「パッケージ / バリエーション / 作品 / 関連資料」の単位で、キャラクターと声優の項目が無い |
| Wikidata の P725 (声優) | × | 項目 JSON と SPARQL は robots.txt で禁止済み ([`wikimedia.md`](../stores/wikimedia.md))。ソーシャルゲームのキャラクター項目が少ない (推測、未測定) |
| Fandom | × | Cloudflare のボット検査で robots.txt も取得できない |

## 2. 声優の記事からゲームを抜く (ja.wikipedia)

記事に到達できた声優 1,966 人 (`crawler/.cache/discovery/wikipedia-kana.json`、2026-09-22 時点) から 30 人を抽出した。

| 測ったもの | 値 |
|---|---|
| 「ゲーム」節を持つ記事 | 30 / 30 |
| 節の中の項目 (入れ子を除く `li`) | 2,666 件 |
| 記事へのリンクを持つ項目 | 1,972 件 (73%) |
| リンク先が存在しない項目 (赤リンク) | 54 件 |
| 括弧つきの文字列 (キャラ名にあたる) を持つ項目 | 2,557 件 (96%) |
| 直前の年の見出しから年が取れた項目 | 2,624 件 (98%) |
| 異なりタイトル | 1,365 |
| 2 人以上 / 3 人以上 / 5 人以上が出ているタイトル | 322 / 109 / 23 |
