# オトバンクへの照会 — 窓口調査と文面草案

Date: 2026-09-18
Status: **草案。未送信。** 送信するかどうかはユーザーが判断する。
関連: `docs/research/store-survey-2026-09-18.md` §2（audiobook.jp）、同 §2-9（利用規約 第15条(15)）

## 0. なぜ照会するか

audiobook.jp の利用規約 第15条（禁止事項）(15) に次の記述がある。

> 当社コンテンツを含む本サービス上のコンテンツについて、当社の事前の許可なく、情報解析（生成AIに学習させることを含むが、これに限らない）をする行為

本プロジェクトが行おうとしている「公開ページから作品情報を取得して自サービスの DB に保存し、一覧表示する」行為がこれに当たるかは、条文からは判断できない。「事前の許可なく」と明記されている以上、実装前に運営元へ照会する。

なお robots.txt は `Disallow: /public/index.php/` のみで、検索・商品ページの取得を禁じていない（同調査 §2-1）。**robots.txt と利用規約が食い違っているのではなく、規約のほうが厳しい**という状態。

### 1-4. 推奨する窓口

**第一候補: 「広報全般に関するお問い合わせ」フォーム、ご用件は「その他お問い合わせ」を選ぶ。**

理由:

- このフォームの説明文だけが「**『株式会社オトバンク』『audiobook.jp』その他サービスへの**…お問い合わせ」と、会社とサービス全体を対象に書かれている。公開されている窓口のうち、コーポレート宛の汎用経路はここだけ
- 「その他お問い合わせ」という選択肢があり、取材・プレスリリース以外を受ける前提になっている。社内で適切な部署へ回されることが期待できる（推測）
- ヘルプセンター（Zendesk）は個人利用者のサポート窓口で、用件が「サービスの使い方」ではないうえ、一次サポート担当が規約解釈の判断権限を持つとは考えにくい（推測）
- 法人版フォームは「audiobook.jp 法人版」という別プロダクトの営業窓口で、用件が違う
- 「音声コンテンツ企画・制作」は制作を**発注する側**向けの窓口で、方向が逆

**第二候補（併用または再送先）: info@otobank.co.jp へ同じ本文をメールする。**

フォームは送信控えが手元に残らないのに対し、メールは送信記録と本文がそのまま残る。やり取りの記録を残したい場合はメールのほうがよい。ただし特商法表示に載る窓口はサービス利用者向けの位置づけなので、まずフォームを使い、**2 週間ほど返信が無ければメールで同じ内容を送る**のが妥当。

### 1-5. A8.net を照会経路にできるか

- audiobook.jp のアフィリエイトは **A8.net 経由**（`store-survey-2026-09-18.md` §2-6 で確認済み）。公式ヘルプに「アフィリエイトについて」の記事がある（`https://otobankhelp.zendesk.com/hc/ja/articles/360001749814`）
- ただし今回、このヘルプセンターは Cloudflare のボット保護に阻まれて本文を取得できなかった（HTTP 403）。記事の存在は otobank.co.jp からのリンクと検索結果のタイトルで確認したが、**本文は未検証**
- A8.net のプログラム一覧はログインが必要で、プログラムの掲載有無・提携条件は未確認

**結論: A8.net は照会経路として使わない。** 提携申請フォームには自サイトの説明を書く欄があるが、広告主が読むとは限らず、読まれても審査担当が規約解釈を判断できるとは考えにくい（推測）。規約解釈の照会はコーポレート窓口で行い、アフィリエイト提携は別途 A8.net で申請するのが筋が通る。ただし照会文の中で「アフィリエイトを利用する可能性がある」と書いておくと、相手が用件を位置づけやすくなる。

### 文面についての補足

- 取得項目を列挙したのは、相手が「どこまでなら可か」を項目単位で答えられるようにするため。曖昧に「作品情報」とだけ書くと、判断できずに止まる
- 「網羅的な取得はしない」「1 日 1 回」「robots.txt を遵守」は、相手の一番の懸念（サーバー負荷と全カタログの複製）を先に潰すために入れている
- 開発中・未公開であることを隠さない。後から「実は既に動かしていた」となるほうが不利
- アフィリエイトに触れるのは、送客によって相手側にも利益がある構図を示すため。売り込みにならないよう 1 行に留める
- **表示の範囲を明示する**のは、「作品情報を表示」だけだと相手が全文転載を想像しうるため。紹介文を転載しないこと、音声を扱わないことを先に書いておくと、相手は負荷とコンテンツ複製の両方について安心して判断できる

## 4. 想定される回答パターンと進め方

### A. 許可される（条件なし、または軽い条件）

- 回答の全文を本ファイルに追記し、日付と窓口を記録する
- `docs/design/architecture.md` に audiobook.jp アダプタの取得方針として条件を明記する
- 実装は `store-survey-2026-09-18.md` §2 の調査結果（`/search?q=` → `/product/{id}`、HTML パース、JSON-LD 無し）に沿って進める

### B. 条件付きで許可される

想定される条件と、それぞれへの対応:

| 条件 | 対応 |
|---|---|
| アフィリエイト提携が前提 | A8.net で先に提携申請し、承認後に実装 |
| 取得頻度の上限（例: 週 1 回） | クローラーのスケジュールを分ける。audiobook.jp だけ別 cron にする |
| 書影の直リンク禁止 | 画像を出さずテキストのみ表示する。または画像を取得しない |
| 出典・リンクの明示 | 作品カードに「audiobook.jp」の出典表記と作品ページへのリンクを付ける |
| 取得項目の限定（例: 価格を出さない） | 該当項目をスキーマから外すのではなく、取得・表示しない分岐を入れる |
| User-Agent の明示 | クローラーの UA に連絡先 URL を入れる |

条件が満たせるかどうかは実装前に判断する。満たせない条件があれば、その部分だけ再照会する。

### C. 断られる、または回答が無い

**「事前の許可なく」と規約に書かれている以上、無回答は許可ではない。** 2 週間待って返信が無ければ info@otobank.co.jp へ 1 度だけ再送し、それでも無回答なら不許可と同じ扱いにする。

いずれの場合も **audiobook.jp のクロールは実装しない。** そのうえで、送客だけを行う選択肢が残る（次節）。

## 5. 断られた場合に取りうる選択肢

アフィリエイトリンクによる送客そのものは、A8.net の提携が通れば通常可能なはず（推測。提携条件は未確認）。作品情報の扱い方には段階がある。上から順に安全。

### 選択肢 1: 検索リンクだけ置く（最も安全。推奨）

声優ページに「audiobook.jp でこの声優の作品を検索する」という外部リンクを 1 本置くだけ。作品情報は一切取得も保存もしない。規約の「情報解析」にも「コンテンツの複製」にも触れない。アフィリエイト提携が通っていれば、そのリンクをアフィリエイトリンクにできる。

欠点: 作品があるかどうかが当サービス上で分からないので、リンクを空振りさせる。

### 選択肢 2: A8.net が提供する素材の範囲で扱う

ASP 経由で配布される商品リンク・バナー・商品データは、広告主が配布を許諾したものなので、audiobook.jp のページを直接取得するのとは扱いが異なる。A8.net に商品データの提供があるかは未確認。

欠点: 提供されるデータの粒度に依存し、ナレーター名が含まれない可能性が高い（推測）。本プロジェクトは声優が軸なので、ナレーター名が無いデータは使えない。

### 選択肢 3: 手動登録のみにする

クロールは行わず、運営者が目で見て作品情報を手で登録する。自動収集ではないので「情報解析」の文言からは外れると読めるが、**不許可の回答を受け取った後にこれを行うのは、回答の趣旨に反する可能性が高い。** 相手が「コンテンツの利用そのものを断った」のか「自動収集を断った」のかを回答文から読み取り、前者なら選択肢 1 に留める。

なお同条 (17)「本サービスの他のお客様の情報の収集行為」は利用者の個人情報を指しており、作品情報は対象外と読める。

### 選択肢 4: audiobook.jp への対応自体を見送る

`store-survey-2026-09-18.md` の総合評価では **第 1 位がポケットドラマ CD、第 2 位が audiobook.jp**。ポケドラは声優タグがあり、代表声優あたりの作品数が audiobook.jp の 2〜3 倍ある。audiobook.jp を落としても、次に着手すべきストアは決まっている。

ただし audiobook.jp のカタログは「本好きの下剋上」ドラマ CD（キャスト 36 名）のようにアニメ声優の出演が厚く、落とすと惜しい。選択肢 1（検索リンク）と組み合わせて、将来の再照会の余地を残すのがよい。
