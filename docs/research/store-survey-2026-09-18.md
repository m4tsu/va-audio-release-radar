## 0. 調査方法とリクエスト実績

- UA: `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/128.0 Safari/537.36`
- `Accept-Language: ja-JP,ja;q=0.9`
- 各サイトの `robots.txt` を最初に取得。禁止パスにはアクセスしていない
- `Crawl-delay` の指定が無いサイトも 5 秒以上の間隔を空けた

| ホスト | リクエスト数 | 上限 |
|---|---|---|
| pokedora.com | 15 | 15（到達） |
| audiobook.jp（`pages.audiobook.jp` 含む） | 14 | 15 |
| www.stellaplayer.jp | 7 | 15 |
| kikubon.jp | 4 | 15 |
| www.animate-onlineshop.jp | 1 | 15 |
| www.amazon.co.jp | 1 | 15 |
| **合計** | **42** | 60 |

pokedora.com は上限に到達したため、後述のとおり一部の項目（作品総数、代表 5 名のうち 2 名）は未計測。

### 対象ストアの選定

必須 2 ストアに加えて 4 サイトを調べた。選定基準は「アニメ声優が出演する、購入可能な日本語音声作品を扱っているか」。

| ストア | 採否 | 理由 |

## 1. ポケットドラマCD（pokedora.com）

運営: 株式会社アニメイト（作品ページの `<meta name="author">` に記載）。

### 1-1. robots.txt

```
User-Agent: *
Disallow: /cart/*
Disallow: /mypage/*
Sitemap: https://pokedora.com/sitemap.xml
```

- `Crawl-delay` の指定なし → 本調査では 5 秒間隔を採用
- 商品一覧 `/products/list.php`、商品詳細 `/products/detail.php`、タグ `/tags/` はいずれも許可されている
- sitemap は index 形式で、`sitemap_page` / `sitemap_corners_1` / `sitemap_features_1` / `sitemap_products_1` / `sitemap_products_2` / `sitemap_tags_1` の 6 本（すべて `.xml.gz`）

### 1-2. 声優からの導線

声優はタグとして一級の概念になっている。

| 用途 | URL の形 |
|---|---|
| 声優タグの作品一覧 | `https://pokedora.com/tags/?tag_type=1&tag_id={id}` |
| ページング・表示件数・並び順つき | `https://pokedora.com/tags/?tag_type=1&tag_id={id}&pageno=1&order=popular&disp_number=30` |
| ストア切り替え | 上記に `&store=men`（オトナ向け）/ `&store=bl` |
| フリーワード検索 | `https://pokedora.com/products/list.php?name={声優名}` |
| 商品詳細 | `https://pokedora.com/products/detail.php?product_id={id}` |

タグページの `<title>` は `声優【佐藤泰臣】のボイス・ASMR、音声配信、シチュエーションCD 一覧 | ポケットドラマCD(ポケドラ)` の形で、声優名がここに入る。

サイト全体が 4 つのストアに分割されている（一般 / BL / オトナ向け / オトナBL）。タグページは既定で「一般」を表示し、他ストアの件数は同じページ内にカウントだけ出る。オトナ向けの 2 ストアは年齢認証の背後にある。

### 1-3. 声優の一覧が取れるか

**一覧ページとしては取れないが、ID の全集合は sitemap から取れる。**

`sitemap_tags_1.xml.gz` に 6,939 件のタグ URL が入っている。

| tag_type | 件数 | 意味（実際にページを引いて確認） |
|---|---|---|
| 1 | 3,161 | 声優 |
| 2 | 1,276 | シリーズ |
| 3 | 412 | レーベル |
| 4 | 2,090 | 原作者・イラストレーター等 |

sitemap には URL しか入っておらず、**声優名は含まれない**。名前を得るには各タグページの `<title>` を引く必要がある。3,161 件 × 5 秒 = 約 4.4 時間の一度きりのバッチになる。

`/tags/`（引数なし）は 404 を返す。声優名から tag_id を引く検索 API `/sapi/json.php?query=...&Operation=Suggest&Service=none` が JS 内に定義されているが、この引数で叩くと 404 が返った。

### 1-4. 作品ページの情報

`products/detail.php?product_id=126232`（ボイスドラマ「おかえり、初恋。」通常版）で確認。

| 項目 | 取得可否 | 備考 |
|---|---|---|
| タイトル | ○ | `<title>` および og:title |
| 声優クレジット | ○（全員） | 「出演声優」欄に全員。各名が `/tags/?tag_type=1&tag_id=...` へリンク |
| 役名 | ○（作品による） | 「ストーリー・キャラクター紹介」に `田口涼介(CV:小林千晃)` の形。自由記述 |
| 発売日 / 配信日 | **×** | 詳細ページにも一覧にも日付表示が無い |
| 価格 | ○ | 税込価格 |
| 再生時間 | × | トラック名は出るが尺は出ない |
| カバー画像 | ○ | `https://pokedora.com/get_image.php?product_id={id}&thumb=large` |
| レーベル | ○ | tag_type=3 へのリンク |
| 収録トラック | ○ | トラック名の一覧 |
| 内容紹介 | ○ | |

**発売日が取れない点が、新着レーダーとしては最大の欠点。** 一覧の並び替えに「新着順」はあるので順序は分かるが、絶対日付は得られない。回避策は初回観測日をこちらで記録すること（後述）。

### 1-5. 一覧の件数制限

- 表示件数は 30 / 50 / 100 から選べる（`disp_number`）。100 件指定が可能
- ページングは `pageno`。robots.txt に該当する禁止は無い
- 総件数は `8件中 1 - 8件目` の形でページ内に出る。さらにストア別の内訳（`一般 (8件) BL (2件) オトナ向け (0件) オトナBL (0件)`）も同じページに出る
- 作品総数は未計測（リクエスト上限に到達したため `sitemap_products_1/2.xml.gz` を取得していない）

### 1-6. アフィリエイトプログラム

ポケドラ単独のプログラムは公開情報では見つからなかった。親会社のアニメイトは「アフィリエイトパートナー募集」を出しており、A8.net とバリューコマースで提携できる。ポケドラでの購入がアニメイトのプログラムの成果対象に含まれるかは公開情報からは確認できない（推測: 別サイト別ドメインなので対象外の可能性が高い）。

### 1-7. 対象声優との重なり

声優名の全リストが取れないため、交差人数は測れない。代表 5 名のうち 3 名を検索した（残り 2 名はリクエスト上限のため未計測）。

| 声優 | 一般 | BL | オトナ向け | オトナBL |
|---|---|---|---|---|
| 上田麗奈 | 8 | 2 | 0 | 0 |
| 斉藤壮馬 | 45 | 98 | 0 | 0 |
| 中村悠一 | 7 | 5 | 0 | 0 |
| 富田美憂 | 未計測 | 未計測 | 未計測 | 未計測 |
| 石見舞菜香 | 未計測 | 未計測 | 未計測 | 未計測 |

一覧の表示は出演声優を 2 名までしか出さないが、検索は全キャストに当たっている。上田麗奈の検索で「千歳くんはラムネ瓶のなか」「ストライクフォール」が出てくるのはそのため（audiobook.jp 側の同一作品のキャストに上田麗奈が含まれることで裏が取れた）。

声優タグが 3,161 件あることから、対象 2,569 人との重なりは大きいと考えられる（推測。実測には 3,161 回の取得が要る）。

### 1-8. DLsite / Audible との重複

- ガガガ文庫のドラマCD（千歳くんはラムネ瓶のなか、ストライクフォール、勇者と勇者と勇者と勇者）は **ポケドラと audiobook.jp の両方にある**。価格はポケドラ ¥1,320、audiobook.jp ¥1,650 と異なる
- DLsite との重複は確認できなかった。`crawler/.cache/discovery/dlsite-works.json`（2,085 件の直近サンプル）に対して上記のポケドラ作品名を照合したが 0 件。ただしこのキャッシュは全カタログではないので、重複が無いことの証明にはならない
- ポケドラのシチュエーションCD / ASMR は DLsite の同ジャンルと商材が近く、レーベル単位で重複しうる（推測）

### 1-9. 利用規約（`/guide/kiyaku.php`）

第 11 条（禁止事項）にクローリング・情報解析を名指しで禁じる条項は**無い**。関連する条項は以下。

> 第11条(禁止事項) ① 利用者は本サービス利用に関して次の各号の行為を行わないものとします。
> ⅰ.当社もしくは第三者の著作権、商標権等の知的財産権を侵害する行為、又は侵害するおそれのある行為
> ⅲ.本サービスによりアクセス可能な当社又は第三者の情報を改ざん、消去する行為。

## 2. audiobook.jp

運営: 株式会社オトバンク。

### 2-1. robots.txt

```
User-agent: *
Disallow: /public/index.php/
```

- これだけ。`Crawl-delay` なし、sitemap 宣言なし → 本調査では 5 秒間隔を採用
- 検索 `/search`、商品 `/product/{id}`、`/audiobook/{id}` はいずれも許可

### 2-2. 声優からの導線

声優（ナレーター）専用のページは無い。フリーワード検索が唯一の導線。

| 用途 | URL の形 |
|---|---|
| キーワード検索 | `https://audiobook.jp/search?q={声優名}` |
| ページング | `&page={n}` |
| ジャンル絞り込み | `&lg[]=anime`（ラノベ・アニメ・ラジオドラマ）。他に business / self-development / culture / language / practical / literature / lecture |
| 並び替え | 「販売日が新しい順」「聴き放題の配信日が新しい順」などがフォームに存在 |
| 商品詳細 | `https://audiobook.jp/product/{id}` |

検索結果はサーバー側でレンダリングされる。ナレーター名は一覧のカードにも全員分そのまま入る。

注意: 検索パラメータは `q`。`keyword` を渡すと 200 が返るが検索は実行されず既定の人気一覧が出る。

### 2-3. 声優の一覧が取れるか

**取れない。** ナレーターのインデックスページも、ナレーター ID も存在しない。声優単位の収集は 1 人 1 検索になる。2,569 人 × 5 秒 = 約 3.6 時間／1 巡。

### 2-4. 作品ページの情報

`/product/239757`（極上voiceメソッド『自分を操る超集中力』）で確認。

| 項目 | 取得可否 | 備考 |
|---|---|---|
| タイトル | ○ | |
| 声優クレジット | ○（全員） | 「ナレーター」欄。一覧カードにも全員入る。最大 36 名の例を確認 |
| 著者 | ○ | |
| 出版社 | ○ | |
| 発売日 | ○ | 「出版日」と「販売開始日」の 2 つ |
| 価格 | ○ | 税込。聴き放題対象 / チケット対象のバッジも付く |
| 再生時間 | ○ | `HH:MM:SS` |
| トラック数 | ○ | |
| カバー画像 | ○ | |
| ジャンル | ○ | 階層つき |
| 作品紹介 | ○ | |

JSON-LD は無い。HTML パースが必要。

### 2-5. 一覧の件数制限

- 1 ページ 20 件
- ページングは `page=`。robots で禁止されていない
- **総件数は表示されない。** ページャは `« » 1 … 17 18 19 20 21 22 23 …` の形で、末尾のページ番号を出さない
- 「ラノベ・アニメ・ラジオドラマ」ジャンルの規模を範囲で測った: `page=40` は 200 で 20 件、`page=200` は 404。つまり **860 件以上 4,000 件未満**。正確な総数は二分探索が必要で、今回はリクエスト予算の都合で打ち切った
- 検索結果は 1 人あたり数ページに収まる。斉藤壮馬でページャが `1 2 3`（41〜60 件）

### 2-6. アフィリエイトプログラム

**あり。** 公式ヘルプに「アフィリエイトについて」の項があり、A8.net 経由で提携する。報酬は新規登録や購入に対して設定されている（金額は ASP 側の公開情報であり、条件は変わりうる）。申請はしていない。

### 2-7. 対象声優との重なり

一覧が取れないので代表 5 名を検索した。

| 声優 | 1 ページ目の件数 | ページ数 | 内容 |
|---|---|---|---|
| 上田麗奈 | 6 | 1 | ガガガ文庫のドラマCD 6 作 |
| 富田美憂 | 1 | 1 | 異星人ASMR 1 作 |
| 石見舞菜香 | 10 | 1 | 「本好きの下剋上」ドラマCD ほか |
| 斉藤壮馬 | 20 | 3 | 朗読・ドラマCD・分割トラック |
| 中村悠一 | 6 | 1 | おやすみロジャー、ドラマCD『王の獣』 |

5 名全員に作品がある。しかも「本好きの下剋上」ドラマCD 10 のキャストは 36 名で、その大半がアニメ出演声優である。**「アニメ声優が出演する音声作品」という条件に対して、カタログの中身が正面から合致している。**

### 2-8. DLsite / Audible との重複

- ガガガ文庫のドラマCD 群がポケドラと重複（1-8 参照）
- Audible との重複は大きいと考えられる（推測）。両者ともビジネス書・文芸のオーディオブックが主力で、同一書籍が別ナレーターで存在する場合もある。今回は Audible 側を取得していないので実測していない
- DLsite との重複は小さいと考えられる（推測）。商材が同人音声とオーディオブックで異なる

### 2-9. 利用規約（`https://pages.audiobook.jp/terms/`）

**データ利用について明確な制限がある。**

> 第１５条（禁止事項）
> (15) 当社コンテンツを含む本サービス上のコンテンツについて、当社の事前の許可なく、情報解析（生成AIに学習させることを含むが、これに限らない）をする行為

同条の他の項:

> (13) …本サービスに不正なアクセスを試みる行為、その他当社による本サービスの運営または他のお客様による本サービスの利用を妨害し、支障を与える行為、またはそのおそれのある行為
> (17) 本サービスの他のお客様の情報の収集行為

カタログ情報を収集して自サービスの DB に載せる行為が (15) の「情報解析」に当たるかは解釈の余地があるが、**「事前の許可なく」と明記されている以上、実装前にオトバンクに照会すべき**。A8.net でのアフィリエイト提携がその照会経路になりうる。

## 3. ステラプレイヤー（www.stellaplayer.jp）

運営: 株式会社ステラワース。女性向け音声作品の配信サービス。

### 3-1. robots.txt

**存在しない。** `/robots.txt` は 404 を返し、SPA のエラーページ HTML が返る。禁止パスの宣言が無いので、5 秒間隔を採用した。sitemap の宣言も無い。

### 3-2. 声優からの導線

**確立された導線が無い。** Next.js の `_buildManifest.js` から全ルートを取得したが、声優・キャストのページは存在しない。

| ルート | 種別 |
|---|---|
| `/product/[id]` | 商品詳細。SSR |
| `/maker/[maker]` | メーカー別 |
| `/archive` | 検索・絞り込み。**クライアントレンダリング** |
| `/ranking`, `/ranking/[top_category]` | ランキング |
| `/general`, `/bl`, `/girls` | カテゴリトップ。SSR |
| `/mypage/follow` | フォロー機能（ストア内に既にある） |

`/archive?keyword={名前}&top_category=GENERAL` で検索できるが、このページには `__NEXT_DATA__` が無く、結果は `api.stellaplayer.jp` への GraphQL 呼び出しで後から差し込まれる。HTTP 取得だけでは結果が読めない。声優での絞り込みクエリパラメータ名は、JS を実行しないと特定できなかった。

### 3-3. 声優の一覧が取れるか

**取れない。** 声優のインデックスページが無い。

ただし商品側には構造化されたクリエイター ID がある（次項）。全商品を舐めれば声優の集合は再構成できる（推測: 商品 ID は連番に見える。総数は未計測）。

### 3-4. 作品ページの情報

`/product/2750`（真郷街 AnotherBlood）の `__NEXT_DATA__` に、構造化された JSON がそのまま入っている。**今回調べた 6 サイトの中で最もきれいなデータ。**

| 項目 | 取得可否 | フィールド |
|---|---|---|
| タイトル | ○ | `name` |
| 声優クレジット | ○（全員・構造化） | `creators[]` に `{id, name, creator_group_id}`。`creator_group_id: 1` が出演者、2 が原作・脚本、3 がイラスト |
| 役名 | △ | 構造化されておらず、説明文ブロックの自由記述 |
| 発売日 | ○ | `release_schedule`、`publish_starts_at`、`preorder_starts_at`（予約開始日） |
| 価格 | ○ | `current_price: {price, is_discounted}` |
| 再生時間 | × | `contents_size` は null。トラック名のみ |
| カバー画像 | ○ | `converted_featured_images` に 800x800 / 634x634 などの png・webp |
| シリーズ | ○ | `series[]` |
| レーベル | ○ | `brand` |
| ジャンル | ○ | `genres[]` |
| 収録トラック | ○ | `audio_tracks.tracks[]` |
| 成人向けフラグ | ○ | `is_adult` |
| レビュー | ○ | `publishedReviews`, `countRatings` |

## 8. 推奨する追加順

### 第 1 位: ポケットドラマCD

**理由: 「アニメ声優の音声作品」との重なりが最大で、声優が設計上の一級概念になっている唯一のストア。**

数字:

| 根拠 | 値 |
|---|---|
| 声優タグの総数 | 3,161（対象 2,569 人と同じオーダー） |
| 斉藤壮馬の作品数 | 一般 45 + BL 98 = 143 |
| 上田麗奈の作品数 | 一般 8 + BL 2 = 10 |
| 中村悠一の作品数 | 一般 7 + BL 5 = 12 |

同じ 3 名について audiobook.jp は 6 / 41〜60 / 6 件。**代表声優あたりの作品数でポケドラが 2〜3 倍多い。** 声優 ID が安定 URL として存在するので、フォロー中の声優だけを差分クロールする設計にきれいに収まる。

実装コスト:

| 項目 | 見積もり |
|---|---|
| 声優名 → tag_id の初回マッピング | 3,161 リクエスト × 5 秒 ≒ **4.4 時間**（一度きり） |
| フォロー声優 1 人あたりの巡回 | 1 リクエスト（`disp_number=100` で大半が 1 ページに収まる） |
| パーサーの難度 | 低。EC-CUBE ベースのサーバーレンダリング HTML |
| 追加で必要な機構 | **発売日が無いため、初回観測日を新着判定に使う仕組み** |

発売日の欠如が最大の課題。`order` に新着順があるので順序は取れる。実運用では「クローラーが初めて見た日」を `firstSeenAt` として記録し、それを新着イベントの日付として扱う設計になる（既存の DLsite / Audible が発売日を持つのに対し、1 ストアだけ意味の違う日付を持つことになる点は設計で明示が必要）。

留意点:
- カタログの重心が BL・オトナ向けにある。斉藤壮馬で 143 件中 98 件が BL。全年齢の一般ストアだけに絞ると魅力が半減する。オトナ向け 2 ストアは年齢認証の背後にあり、現行の全年齢方針と衝突する
- アフィリエイトの成果対象になるか不明。収益面では期待しないほうがよい

### 第 2 位: audiobook.jp

**理由: メタデータの質が最も高く、発売日とアフィリエイトの両方がある。ただし利用規約の照会が前提。**

数字:

| 根拠 | 値 |
|---|---|
| 代表 5 名すべてに作品あり | 6 / 1 / 10 / 41〜60 / 6 件 |
| ラノベ・アニメ・ラジオドラマのジャンル規模 | 860 件以上 4,000 件未満 |
| 1 作品あたりのキャスト数 | 最大 36 名を確認（本好きの下剋上 ドラマCD10） |

キャスト 10〜36 名のドラマCD が並ぶので、**1 作品が多数のフォロー声優にヒットする。** 作品数は少なくても、フィードに乗る回数は作品数以上になる。

実装コスト:

| 項目 | 見積もり |
|---|---|
| フォロー声優 1 人あたりの巡回 | 1〜3 リクエスト（20 件／ページ） |
| 2,569 人の全巡回 | 2,569 リクエスト × 5 秒 ≒ **3.6 時間**／1 巡 |
| パーサーの難度 | 低〜中。サーバーレンダリング HTML、JSON-LD は無い |
| 声優 ID | 無い。毎回キーワード検索するしかない。同名・表記揺れのノイズ対策が要る |

**着手前にオトバンクへ照会すること。** 利用規約 第 15 条 (15) が「当社の事前の許可なく、情報解析…をする行為」を禁じている。この条項がある以上、実装してから問題になるより先に確認するほうが安い。A8.net でのアフィリエイト提携が照会の入り口になりうる。

### 第 3 位: ステラプレイヤー（保留）

**理由: データ構造は 6 サイト中で最良だが、声優 → 作品の導線が存在しない。**

商品ページの `__NEXT_DATA__` には `creators[]`（出演者が `creator_group_id: 1` で構造化）、`release_schedule`、`preorder_starts_at`、価格、シリーズ、レーベル、ジャンルがそのまま入っており、パースは自明。予約開始日まで取れるのは他のどのストアにも無い利点。

しかし声優のインデックスも声優別ページも無く、検索はクライアントレンダリングのため HTTP 取得だけでは結果が読めない。声優単位で追うには**全商品を舐めて `creators` から逆引きインデックスを自前で構築する**しかない。商品総数が未計測なのでコストを見積もれていない。

着手する場合の前提作業: 商品 ID の範囲を確認し、全商品クロールの所要時間を出す。これが現実的な時間に収まるなら、データ品質の高さから優先度は上がる。

### 第 4 位: kikubon（見送り推奨）

**理由: 規模が小さすぎる。**

| 根拠 | 値 |
|---|---|
| 声優・ナレーター総数 | 138 |
| 対象 2,569 人との交差 | 56 |
| 対象側のカバー率 | **2.2%** |
| 斉藤壮馬の作品数 | 6 |

全リストが 1 ページで取れてクローリングは容易だが、フォロー中の声優の 2.2% にしか届かない。しかも発売日が無く、価格はポイント建てで他ストアと横並びにできず、アフィリエイトも無い。**得られるものに対して、ストア 1 つ分の保守面積が見合わない。**

追加するなら、他の 3 ストアがすべて安定してからの「おまけ」に留める。
