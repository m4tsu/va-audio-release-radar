# ゲームの公式サイト (HoYoverse 以外)

読者: ゲームのキャストを公式サイトから取り込む前の人。タイトルを足す前の人
更新: robots.txt と利用規約を取り直したら (差分が無くても最終確認日を更新する)。タイトルを足したり外したりしたら
削除: ゲームのキャストを公式サイトから取らなくなったら

**ストアではない。** ゲームのキャラクターと日本語の声優の対の供給元。
HoYoverse の 3 タイトルは [`hoyoverse.md`](./hoyoverse.md)、鳴潮は [`gamewith.md`](./gamewith.md)。
どのタイトルを載せ、どの供給元から取るかは
[`docs/decisions/0018-game-cast-from-official-sites.md`](../decisions/0018-game-cast-from-official-sites.md)、
測定は [`docs/research/game-cast-official-sites-2026-09-25.md`](../research/game-cast-official-sites-2026-09-25.md)。
共通の原則は [`README.md`](./README.md)。

ここに載せるのは、`0018` で使うと決めたタイトルの公式サイトだけ。調べて使わないと決めたサイトの記録は
研究ノートの「タイトルごとの一覧」にある。

## レート間隔

どのホストも `Crawl-delay` を置かず、枠も公表していない。1 タイトルの取得は、一覧 1 枚から個別ページ数十枚まで
(アイドル名鑑のシンデレラガールズだけが約 190 枚) で、月に 1 回引き直すだけなので、`crawler/lib/fetch.ts` の
既定値を使う。

## 使ってはいけない URL

- キャラクターのページ以外 (ニュース、ゲームの規約以外の本文、画像、ボイス、動画)。キャストの対にしか使わない
- WordPress の管理画面 (`wp-admin` を含むパス)。各 robots.txt が禁じている
- アイドル名鑑の検索結果のページ送りや絞り込みの組み合わせ。一覧は各ブランドの 1 枚だけを引く

## 既知の落とし穴

- **キャラと声優が 1 ページにまとまるサイトと、1 人 1 ページのサイトがある。** 後者は一覧から個別ページの
  リンクを拾い、リンクの数だけ引く (プロジェクトセカイ・魔法使いの約束・アサルトリリィ・アイドル名鑑・学園アイドルマスター)
- **声の無いキャラがいる。** アイドル名鑑のシンデレラガールズでは、標本 12 人のうち 6 人に CV の欄が無い
- **ツイステッドワンダーランドは声優名が画像の alt にしか無い。** `キャラ名 声優名` を最後の半角空白で分ける。
  声優名に空白が入る人が来ると分け方を誤る (推測)
- **異体字の揺れがある。** あんさんぶるスターズ!! と魔法使いの約束は「天﨑滉平」、台帳は「天崎滉平」
- **声優名にローマ字の括弧が付くサイトがある。** ドールズフロントライン2 は `豊崎愛生 (Aki Toyosaki)`。
  括弧を落としてから照合する。日本語の声優の欄が無いキャラもいる
- **1 人の声優が 2 キャラを持つ。** 白猫プロジェクト (不採用) とあんさんぶるスターズ!! (葵ひなた・ゆうた)
- **ヘブンバーンズレッドは歌唱担当が同じ欄に並ぶ。** 声優の欄と歌唱の欄を分けて読む

## 未確認の項目

- アイドル名鑑と学園アイドルマスターの利用規約 (リンクが見つからない)
- アイドル名鑑の 765 プロのアイドルが、どのブランドの一覧に入るか (THE IDOLM@STER の一覧にある (推測))
- D4DJ のプロジェクトサイトの 36 人とゲームサイトのリンク 36 件が同じ集合か
- 刀剣乱舞ONLINE (`www.toukenranbu.jp`): Node の fetch が証明書の検証に失敗し、`crawler/lib/fetch.ts` から取れない。
  使えるようになるまで対象に入れない
