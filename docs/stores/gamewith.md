## robots.txt

**最終確認日: 2026-09-25** (`https://gamewith.jp/robots.txt`)。全文:

```

Sitemap: https://gamewith.jp/sitemap.xml
```

`User-agent` のグループも `Disallow` も `Crawl-delay` も無い。robots では、どのパスも禁じられていない。

比べた相手の Game8 (`https://game8.jp/robots.txt`、同日) は `User-agent: *` のグループを持たず、`Googlebot` の
グループと、GPTBot / ClaudeBot / CCBot / Bytespider など収集系のボット約 40 種を名指しした `Disallow: /` の
グループだけを置いている。

### 利用規約 (`https://gamewith.jp/terms`、最終確認日 2026-09-25)

禁止事項のうち、取得に関係しうるのは次の 3 つ。

> (14)通常に本サービスを利用する行為を超えてサーバーに負荷をかける行為

> (17)本サービスによって提供される機能を複製、修正、転載、改変、変更、リバースエンジニアリング、逆アセンブル、逆コンパイル、翻訳あるいは解析する行為

> (19)本サービスの全部又は一部を商業目的で、使用方法を問わず利用する行為（それらの準備を目的とした行為も含みます。）

自動取得・スクレイピング・クローラを名指しする条項は無い。

この規約をどう読んで取得するかは [`0017`](../decisions/0017-game-cast-from-official-sites.md) が決めている。
キャラ名と声優名の対は事実であり、(17) の対象の「機能」にも著作物にも当たらないと読む。(19) は本サービス
(記事・機能) そのものを商業目的で使う行為を指すと読み、事実の対を取ることは含まないと読む。
記事の文章・代表作の欄・画像は取らず、載せない。(14) に当たらないよう、1 ページを月に 1 回だけ引く。
運営元から申し出があれば取り下げる。

## レート間隔

robots に `Crawl-delay` が無い。取るのは声優一覧の 1 ページを月に 1 回だけなので、`crawler/lib/fetch.ts` の既定値を使う。

## 使ってはいけない URL

- 声優一覧以外の記事 (キャラごとの性能・評価の記事など)。キャラ名の行はそこへリンクしているが、辿らない
- 他のタイトルの記事。GameWith から取るのは鳴潮だけ

## 既知の落とし穴

- **声優一覧のページは記事番号で指す** (`/wutheringwaves/<番号>`)。番号はタイトル一覧に書く。
  記事が差し替えられると番号が変わりうる (推測)
- **1 行に声優が複数入る。** 主人公は男女の 2 人が「、」で区切られる
- 表の手前に「新キャラの声優」の節があり、同じ人がもう一度出る。表の行だけを数える
- 異体字で書かれた名前がある。`白熊寬嗣` (「寛」でなく「寬」) は台帳と一致しない

## 未確認の項目

- 未実装のキャラクターの行があるか、あればどう見分けるか
- 記事の更新の頻度 (新キャラの発表から表に入るまでの日数)
