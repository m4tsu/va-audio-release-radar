# HoYoverse の公式サイト (原神 / 崩壊:スターレイル / ゼンレスゾーンゼロ)

読者: HoYoverse のゲームのキャストを取り込む前の人。そのホストへアクセスする前の人
更新: robots.txt と利用規約を取り直したら (差分が無くても最終確認日を更新する)。キャラクターのページの作りが変わったと分かったら
削除: HoYoverse のタイトルをゲームのキャストの供給元から外したら

**ストアではない。** ゲームのキャラクターと日本語の声優の対の供給元。取り込みは未実装。
採否は [`docs/decisions/0017-game-cast-from-official-sites.md`](../decisions/0017-game-cast-from-official-sites.md)、
測定は [`docs/research/game-cast-official-sites-2026-09-25.md`](../research/game-cast-official-sites-2026-09-25.md)。
共通の原則は [`README.md`](./README.md)。

3 タイトルとも公式サイトのキャラクターページは SPA で、HTML に本文が無い。ページ自身が
コンテンツ API (`sg-public-api-static.hoyoverse.com`) の一覧取得を呼び、各項目の拡張欄に
キャラ名と声優名が入っている。取り込みはこの API を、ページが呼ぶのと同じ形で GET する。

## robots.txt

**最終確認日: 2026-09-25。**

次のホストはすべて **HTTP 404** を返す。

- `genshin.hoyoverse.com` / `hsr.hoyoverse.com` / `zenless.hoyoverse.com` / `houkai3rd.hoyoverse.com`
- `sg-public-api-static.hoyoverse.com` (コンテンツ API)

禁止パスの宣言も `Crawl-delay` も無い。robots では、どのパスも禁じられていない。

### 利用規約 (最終確認日 2026-09-25)

原神 (`https://genshin.hoyoverse.com/ja/company/terms`)、崩壊:スターレイル
(`https://hsr.hoyoverse.com/ja-jp/company/terms`)、ゼンレスゾーンゼロ (公式サイトの「利用規約」。本文はコンテンツ API が返す)
の 3 つは同じ形をとる。どれも運営を COGNOSPHERE PTE. LTD.、「本サービス」を日本国内で提供するゲームと、
それに関連して利用者に提供する一切のサービスと定める。禁止事項のうち、取得に関係しうるのは次の 4 つ。

> 4) 当社又は第三者の著作権その他の知的財産権、肖像権及びパブリシティ権その他の人格権ならびに所有権その他の財産権を侵害する行為。

> 11) 当社の承認を得ずに行われる、営利を目的とする行為。

> 12) 当社が本サービスを通じて提供する各種コンテンツ（有料コンテンツ・サービスで提供される、コンテンツ・サービスに限定されません。）を不正な方法で取得する行為、又はこれを助長する行為。

> 20) 外部ツール(BOT)もしくはCOGNOSPHERE PTE. LTD. から公式に提供していないプログラムを使用し、自分が有利にゲーム進行し、もしくは正常なサービス利用を妨げる行為。

BOT を名指しするのは 20) だけで、その対象は「自分が有利にゲーム進行し、もしくは正常なサービス利用を妨げる」行為に
限られている。スクレイピング・クローラ・データの抽出を名指しする条項は無い。

この規約をどう読んで取得するかは [`0017`](../decisions/0017-game-cast-from-official-sites.md) が決めている。
キャラ名と声優名の対は事実であり、著作権の対象として取らない。11) はゲームの利用者に向けた条項と読む。
12) の「不正な方法」と 20) の「正常なサービス利用を妨げる」に当たらないよう、公開ページが自分で呼ぶ URL だけを、
ページと同じ形で、月に 1 回だけ引く。
取るのはキャラ名と声優名だけで、画像・ボイス・説明文は取らない。

## レート間隔

robots に `Crawl-delay` が無く、API の枠も公表されていない。1 タイトルは数リクエスト
(キャラクターの陣営ごとのチャンネル数) で、月に 1 回引き直すだけなので、`crawler/lib/fetch.ts` の既定値を使う。

## 使ってはいけない URL

- **チャンネル番号の総当たり。** キャラクターが入るチャンネルの番号はページの JS に書かれていない。
  測定のときは番号を順に引いて探したが、取り込みでは探した番号をタイトル一覧に書いて、その番号だけを引く
- ログインや端末識別の API (`passport-api-*.hoyoverse.com`、`sg-public-data-api.hoyoverse.com/device-fp/…`)。
  キャラクターのページもこれを呼ぶが、キャストの取得には要らない
- ボイスの音声ファイルと画像 (`fastcdn.hoyoverse.com/content-v2/…`)。取らない

## 既知の落とし穴

- **声優名の欄の名前がタイトルごとに違う。** ゼンレスゾーンゼロは声優名と言語の欄の組、崩壊:スターレイルは
  声優名だけの欄、原神は数字の ID の欄。1 つの抽出器で扱うなら、欄の名前をタイトル一覧に持たせる
- **言語の欄はゼンレスゾーンゼロにだけある** (値は「日」)。日本語サイトの応答を引いても、他の言語の声優が
  入る欄があるかはタイトルごとに確かめる
- **1 欄に 2 人が入ることがある。** `安野希世乃/玄田哲章` の形。区切って両方を照合する
- **簡体字で書かれた名前がある。** `斋藤千和` (「斎」でなく「斋」)。正規化では畳まれず、台帳と一致しない
- **崩壊3rd の拡張欄には声優の欄が無い** (2026-09-25)。同じ API でも取れない
- 原神は同じキャラクターが「全キャラ」のチャンネルと地域ごとのチャンネルの両方に入る。どちらかだけを引く
