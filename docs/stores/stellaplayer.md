# ステラプレイヤー (www.stellaplayer.jp)

読者: ステラプレイヤーへアクセスする前の人。取り込みを実装する前の人
更新: robots.txt と利用規約を取り直したら (差分が無くても最終確認日を更新する)。使う URL の形や
`__NEXT_DATA__` の読み方を変えたら
削除: ステラプレイヤーを対応ストアから外したら

**取り込みは未実装。** アダプタは無い。外部アクセスは `crawler/lib/fetch.ts` を通す。
共通の原則は [`README.md`](./README.md)。

運営は株式会社ステラワース。女性向けを中心にした音声作品の直販。
サイトは Next.js の pages router で、サーバーで描くページは `__NEXT_DATA__` に構造化された JSON を持つ。

追加するかどうかの結論と手順は
[`docs/decisions/0011-add-stellaplayer.md`](../decisions/0011-add-stellaplayer.md)。

## 1. robots.txt

**最終確認日: 2026-09-20** (`https://www.stellaplayer.jp/robots.txt`)。

**存在しない。HTTP 404 が返る。** `https://www.stellaplayer.jp/sitemap.xml` も HTTP 404 である。

ここから導けること:

- 禁止パスの宣言が無い → 字面で照合する対象が無い。どのパスも robots では禁じられていない
- `Crawl-delay` の宣言が無い → 間隔はこちらで決める (§2)
- sitemap が無い → **全商品の URL を列挙する手段がこのホストに無い** (§3 の「商品ページ」)

### 利用規約 (`https://www.stellaplayer.jp/terms`、最終確認日 2026-09-20)

**第 10 条 (禁止事項) の全 13 号に、情報解析・自動取得・クローリングを名指しする号は無い。**
audiobook.jp が置いている「当社の事前の許可なく、情報解析…をする行為」に当たる条項が無い、という意味である
([`README.md`](./README.md) の表で audiobook.jp が未着手なのはその条項があるため)。

取得の仕方に関係しうるのは同条の次の号:

> 第三者の設備又は本サービス用設備(当社が本サービスを提供するために用意する通信設備、電子計算機、
> その他の機器およびソフトウェアをいい、以下同様とします)に無権限でアクセスし、又はその利用もしくは
> 運営に支障を与える行為(与えるおそれのある行為を含む)。

> 当社もしくは第三者の著作権、商標権等の知的財産権を侵害する行為、又は侵害するおそれのある行為

**取得物の再掲は第 13 条 (著作権等の帰属) が制限している。**

> ② 利用者は、本サービスを提供するWEBサイト上に掲載、もしくは、本サービスを通じて提供される、
> いかなる画像データ、写真、映像、文章、音楽、音声、ソフトウェア等(以下総称して「データ」といいます)も、
> 以下に挙げるような著作権法で認められた私的利用の範囲を超える利用はできないものとします。
>
> データの一部といえども、それを複製し、第三者に配布・販売したり、出版、上映、放送、
> ウェブサイトへの掲載等のために使用すること
>
> データの一部といえども、それを編集・加工して前号の行為を行うこと

導けること: **説明文と画像の本体を自分の画面に載せない。** 載せてよいのは、
事実の記述にあたるタイトル・出演者名・発売日・レーベルと、ストアへのリンクまで。
カバー画像を出すなら、他ストアと同じく**このストアの配信元 URL を `<img src>` にそのまま渡す**形にして、
複製物を自分で配らない。

## 2. レート間隔

> **実装の値は `crawler/lib/fetch.ts` の `rateLimitFor()` が持つ。食い違ったらコードが正。**
> この節は、なぜその値なのかを書く場所であって、値を複製する場所ではない。

**専用のキーを置かず、未知のホストに当たる既定値をそのまま使う。**

robots.txt が無く `Crawl-delay` の指定が無いので、何秒が妥当かは相手にしか分からない。
短くしてよい根拠 (robots の指定、公開されている API 枠) が 1 つも無いため、既定値より短くしない。

既定値で走ったときのスループットの実測は
[`docs/research/stellaplayer-2026-09-20.md`](../research/stellaplayer-2026-09-20.md) の
「調査方法とリクエスト実績」。全件 1 巡と日次のコストも同じ文書の「全商品を 1 巡するコスト」にある。

## 3. 使う URL

**サーバーで描くのは次の 4 経路だけ。** 他のページは静的に書き出されていて、HTML に中身が入らない
(`__NEXT_DATA__` の `pageProps` が空)。判別は `__NEXT_DATA__` の `gssp` で付く。

### 新着一覧 (カテゴリトップ)

```
https://www.stellaplayer.jp/general
https://www.stellaplayer.jp/bl
https://www.stellaplayer.jp/girls
```

`__NEXT_DATA__` の `props.pageProps.dehydratedState.queries[0].state.data` に
`newProducts` (10 件) と `preorderProducts` が入る。並びは `publish_starts_at` の降順。
**3 つ合わせて 1 日 3 リクエストで全カテゴリの新着を見られる。**
許可の根拠: robots.txt が無く、禁止パスの宣言が存在しない (§1)。

### 商品ページ

```
https://www.stellaplayer.jp/product/{id}
```

`__NEXT_DATA__` の同じ位置に `product` が入る。**出演者を知るにはここを引くしかない** (§5)。
`{id}` は 1 から始まる整数。sitemap も一覧 API も使えないので、
**全件を舐めるときは ID を 1 から順に引く**ことになる。

### 正規の商品 URL (保存する `productUrl`)

上の商品ページの URL をそのまま使う。クエリパラメータは付けない。

## 4. 使ってはいけない URL

| 形 | 理由 |
|---|---|
| `api.stellaplayer.jp` の GraphQL | 禁止ではなく**未調査**。`/archive` の裏でブラウザが叩いている別ホストで、規約上の扱いも枠も確認していない。使う前に §1 と同じ手順でこのホストを調べ直す |
| `/archive` (`keyword` / `top_category` / `page` を付けた形) | 禁止ではなく**中身が入らない**。静的書き出しで `pageProps` が空。結果はクライアント側の取得で差し込まれる |
| `/` (トップ) | 同上。`pageProps` が空で、新着も載っていない |
| `/cart`、`/mypage/*` | 購入とアカウントの経路。取得する理由が無い |
| `/product/{id}` の HTTP ステータスで存在を判定する形 | **動くが誤る**。存在しない ID でも HTTP 200 が返る (§6) |

## 5. 取得できる項目 / できない項目

セレクタではなく `__NEXT_DATA__` の JSON のキーで読む。HTML の DOM を当てにしない。

### 新着一覧 (カテゴリトップ)

| 項目 | 可否 | キー |
|---|:--:|---|
| 商品 ID | ○ | `id` |
| タイトル | ○ | `name` |
| 発売日 | ○ | `release_schedule` |
| 掲載開始日時 | ○ | `publish_starts_at` (並び順の基準) |
| 販売状態 | ○ | `sale_status` |
| 成人向けフラグ | ○ | `is_adult` |
| 価格 | ○ | `current_price` |
| レーベル | ○ | `brand` |
| カバー画像 | ○ | `converted_featured_images` |
| **出演者** | **×** | `creators` が無い。商品ページが要る |
| **カテゴリ** | **×** | `top_category` `category` が無い。どのカテゴリトップから来たかで代用する |
| 予約開始日時 | × | `preorder_starts_at` が無い |
| 総件数・次ページ | × | 件数もページ送りの手段も入っていない |

### 商品ページ

| 項目 | 可否 | キー / 備考 |
|---|:--:|---|
| **出演者 (全員)** | ○ | `creators[]` のうち `creator_group_id` が `"1"` のもの。`name` と、このストア内の `id` を持つ |
| 原作・脚本 | ○ | `creators[]` の `creator_group_id` が `"2"` |
| イラスト | ○ | `creators[]` の `creator_group_id` が `"3"` |
| タイトル | ○ | `name` |
| 発売日 | ○ | `release_schedule` |
| **予約開始日時** | ○ | `preorder_starts_at`。**調べた 6 サイトでこれが取れるのはここだけ** |
| 掲載開始日時 | ○ | `publish_starts_at` |
| カテゴリ区分 | ○ | `top_category` (`GENERAL` / `BL` / `GIRLS`) |
| 商品カテゴリ | ○ | `category` (ドラマ / シチュエーション / 歌・サントラ) |
| 成人向けフラグ | ○ | `is_adult` |
| レーベル | ○ | `brand` |
| シリーズ | ○ | `series[]` |
| ジャンル | ○ | `genres[]` |
| 収録トラック | ○ | `audio_tracks.tracks[]` (名前だけ) |
| カバー画像 | ○ | `converted_featured_images` (複数の寸法と形式) |
| 説明文 | ○ | `converted_descriptions_blocks` (`text` / `headline` / `youtube` のブロック配列)。§1 の第 13 条により本体は載せない |

## 6. 既知の落とし穴

- **存在しない ID でも HTTP 200 が返る。** `product` が `null` になるだけで、
  ステータスコードもエラーページの語句も出ない。**`product === null` で判定する**
- **新着一覧に出演者が無い。** 一覧で対象声優を判定できないので、
  新着の商品ページを 1 件ずつ引いてからでないと「対象声優が 1 人も出ていない作品は保存しない」
  ([`docs/product.md`](../product.md) の「対象作品」) を判定できない
- **カタログの大半は 1 人芝居のシチュエーション CD で、対象声優に 1 人も当たらない。**
  当たるのは `category` が「ドラマ」の層に偏る。測定は
  [`docs/research/stellaplayer-2026-09-20.md`](../research/stellaplayer-2026-09-20.md) の「対象声優との重なり」
- **`creators` には人名でない値が混じる。** `creator_group_id` が `"2"` の側に `ほか` が入っていた。
  出演者として使う `"1"` に混入するかは未確認 (§7)
- **`/archive` は HTTP 取得だけでは読めない。** 2026-09-18 の調査時点と 2026-09-20 で変わっていない。
  声優名での絞り込みも総件数もこの経路にある
- **声優のページが無い。** 声優から作品への導線はサイトに存在しない。
  このストアは声優起点で引けず、新着一覧と全件走査でしか作品を集められない
- **1 つの作品に通常版と特典版が別 ID で並ぶことがある。** `editionGroup` というキーがあるが、
  観測した範囲では常に `null` だった

## 7. 未確認の項目

- **商品の総数の確定値。** ID を等間隔に引いた標本からの推定しか無い。確定値は `/archive` の裏の
  別ホストにしか無く、そのホストは未調査 (§4)
- **新着一覧を 10 件より多く取れるか。** サーバー側の問い合わせは引数が固定で、
  ページ送りの手段が HTML からは見えない
- **成人向け商品が HTTP 取得だけで見えるか。** `is_adult` というキーはあるが、
  取得した範囲では `true` の商品が 1 件も無かった。年齢確認の導線の有無も未確認。
  R18 を載せない ([`decisions/0003`](../decisions/0003-no-r18-keep-bl.md)) ので、
  取り込む前にこのフラグで確実に除けるかを確かめる
- **`sale_status` の全語彙。** 販売終了を表す値があるか。
  ([`decisions/0008`](../decisions/0008-no-price-no-availability.md) の取り下げ判定に要る)
- **`creator_group_id` の全語彙**と、`"1"` に人名でない値が入りうるか
- **`product` が `null` になる理由。** 欠番・非公開・削除を区別する材料が無い
- **他ストアとの作品の重複。** DLsite やポケットドラマ CD と照合していない
- **アフィリエイトプログラム。** このホストの取得物には見当たらなかった
